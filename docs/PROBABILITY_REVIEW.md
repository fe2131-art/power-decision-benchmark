# Final Revision and Confidence Evaluation Audit (2026-11-09)

> Historical document from the initial offline audit. For current results see [README](../README.md) and [results/SUMMARY.md](../results/SUMMARY.md).

## Evidence Checked

- TypeSafe official [Confidence](https://docs.typesafe.ai/confidence): `confidence` is a concentration statistic derived from the probability distribution of a Choice/Score. It is not the same as the selected probability.
- TypeSafe official [WorkflowEvals](https://github.com/typesafe-ai/WorkflowEvals) and [evaluation site](https://evals.typesafe.ai): agreement, time, and cost of business workflow execution against the models' reference consensus. This is not a human-produced field gold standard.
- Independent [jev-benchmarking](https://github.com/AppliedMachineLearning-Lab/jev-benchmarking) / [jev-benchmarks](https://github.com/AbdelStark/jev-benchmarks): referenced for classification, calibration, selective automation, probability-vector consistency, and bootstrap.

## Improvements in This Revision

1. The previous 48 items and the 10 curated items are retained, and the default set is changed to the 474 hard items. Correct answers and rationales are included.
2. Fixed split so that the 47 series of similar texts do not cross partitions (124 tuning / 350 test).
3. GPT-6 Luna as a standard LLM can be evaluated in `--llm-probabilities` mode, as JSON with self-reported probabilities. When this option is not specified, probability metrics are recorded as missing, not as zero.
4. Candidate probabilities from OpenAI Decisions, Clef-Flash, and d1-2B, and the provider's `confidence`, are stored in **separate columns**.
5. Implemented ECE, Brier, NLL, reliability CSV, Risk–Coverage, AURC, tuning-only threshold selection, series-level bootstrap CIs, and cause-state contrast triplet evaluation.
6. API failures, missing probabilities, probability-sum errors, and mismatches between the prediction and the maximum probability are not mixed into probability calibration or automatic acceptance. All scheduled items are included in the denominator.
7. Generated data, gold labels, and the split manifest can be regenerated byte-for-byte.

## Verification Not Yet Completed

- **Live OpenAI API calls and GPU inference for Clef-Flash/d1-2B have not been run.** Each model ID, SystemOne compatibility, and response shape must be checked on actual hardware.
- The error rate at adoption must be verified in the real environment with real data. The 0.05 threshold is an **empirical threshold-selection rule** for the demo evaluation, not a safety guarantee.
- The official TypeSafe formula for `confidence` is explained here, but **the Jev API is not included in this comparison**. We do not assume that the `confidence` fields of Cloudflare/Liquid/OpenAI share the same definition.
- There is not yet a human-labeled gold set for production, an equipment distribution, field evaluation of equipment failures, or a speed comparison on the same hardware.
- All 474 items are synthetic memos designed by hand. They are not representative of real-world bias or out-of-distribution anomalies.
